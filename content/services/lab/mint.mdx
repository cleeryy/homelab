Mint is the parked lab desktop: a full Linux Mint VM for the rare task that wants a GUI rather than a shell. It lives on ADMIN (VLAN 10, DHCP) precisely so it never touches the production data path — a convenience machine, isolated by design, powered on but mostly idle. Nobody's evening is ruined if it vanishes; somebody's afternoon gets easier the one time a year a browser inside the lab network is needed.

## Placement

The desktop is VM `10001` on `pve3`, attached to `vmbr1` with tag 10 and addressed via DHCP, an address unverified as of 28/09/2026.

## Status

The VM is running with no ingress and no monitoring. The QEMU guest agent flag is set.

## Dependencies

Its only dependency is OPNsense DHCP on ADMIN (`10.1.10.100-199`), which hands it whatever address it currently holds.

## Failure impact

A failure here has no production impact — lab convenience only. The VM can be rebuilt or simply left off without anything else noticing.

## Known gaps

Its current DHCP lease and the desktop environment need confirming, and the decommissioning decision is still open (see the [migration plan](/architecture/migration-plan)). One login answers the first; one decision closes the second.
