Last synced with live infrastructure: **September 2026**.

You cannot run what you cannot see, and this homelab is mid-migration between two ways of seeing. Beszel was the first answer: a lightweight server with an agent on every Docker host, great for glancing at CPU graphs but blind to everything else. Prometheus and Grafana are the second answer: real metrics collection with the Proxmox exporter and *arr exporters feeding in, aimed at dashboards and eventually alerts. Both run today. Until Grafana is declared canonical and Beszel is switched off, check Grafana first for platform questions and Beszel for the legacy Docker VMs.

## Observed at the last snapshot

- `QBittorrent` reports `gluetun` as **unhealthy** (recurring; kills download egress).
- `Nextcloud` has reported `portainer` restarting (transient).
- `Jelly` reports high memory usage on the `jellyfin` container during transcoding (transient).
- CrowdSec on OPNsense shows port-scan bans including the Caddy host itself — likely proxy log-noise; rule tuning pending.

These are transient observations; they should not be used to draw long-term conclusions.

## Known gaps

Grafana is up but unfinished as a practice: no dashboards-as-code, no retention statement, no alerting channel — monitoring that cannot wake anybody is just graphs. Prometheus scrape inventory (which exporters, which intervals) is similarly tribal knowledge. And Beszel still needs its decommissioning date once Grafana coverage is confirmed rather than assumed.
