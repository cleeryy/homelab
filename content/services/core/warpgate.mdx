Last synced with live infrastructure: **September 2026**.

There is exactly one door into this infrastructure over SSH, and this is it. Warpgate exists so that no guest ever needs its port 22 reachable from the internet: the firewall forwards WAN SSH to Warpgate alone, Warpgate verifies who you are against Authentik, and only then proxies you to the target machine. Day to day that means one SSH key, short hostnames, and per-user policies instead of scattered `authorized_keys` files. If you are debugging at 2 AM and SSH hangs, check these two things in order: is Warpgate itself up, and can it still talk to Authentik.

## Components

| Kind | ID | Name | Host | Function |
|------|----|------|------|----------|
| LXC | `222` | `warpgate` | `pve3` | SSO SSH bastion, `10.1.20.22` (4 GB RAM) |

## Access paths

| Path | Route | Auth |
|------|-------|------|
| SSH from WAN | OPNsense NAT `:22` → `10.1.20.22:2222` | SSO (Authentik) — no raw keys |
| HTTPS admin | `warpgate.cleeryy.cloud` → Caddy → `https://warpgate:8888` | SSO |

Direct SSH to guests from WAN is denied by design; everything passes through Warpgate policies. Local SSH access uses `~/.ssh/warpgate_ed25519` via the `ssh.cleeryy.cloud` bastion endpoint with short hostnames (`pve3`, `pbs`, `caddy`, …), non-interactive flags, and 30 s keepalives (see the operator runbook, not this wiki).

## Role

Warpgate is the single SSH entry point for the whole homelab: Proxmox nodes (via `pct`/`qm` from the node shell), LXCs, and any SSH-enabled guest. It is in the critical backup job (02:00, keep-last 7).

## Failure impact

- Warpgate down → no SSH access from WAN until it is restored (local console via Proxmox still works).
- Authentik down → Warpgate SSO validation fails; same effect.

## Known gaps

The policy inventory — which SSO users and groups can reach which targets — has never been written down, and neither has the session logging posture. Both are worth an evening: access policy is the actual security boundary here, and logs are what turn "someone was in" from a suspicion into a timeline.
