## Purpose

This Fumadocs site is the canonical documentation surface for the homelab. It is deployed from the `cleeryy/homelab` repository (`homelab-wiki` package).

## Placement

- **Built** by Dokploy on `obiwan` (CT `205`) from the `main` branch.
- **Run** as the Dokploy swarm service `homelab-documentation-homelabdocsapp`, with host port `3545` published → container `3545`.
- **Exposed** at `homelab.cleeryy.cloud` via Caddy (`reverse_proxy obiwan:3545`). No SSO (deliberate, public documentation).
- See [Operations > Dokploy](/operations/dokploy) for the deployment procedure. Key lesson: a Dokploy app is unreachable from Caddy until its port is explicitly published and the app redeployed.

## Relation to Docmost

- Docmost runs as LXC `109` on `pve1` and is still present from the previous setup.
- Fumadocs replaces Docmost as the canonical documentation layer. Migrating remaining content out of Docmost is tracked in the [migration plan](/architecture/migration-plan).

## Build and run

- Stack: Next.js 16 + Fumadocs v16, pnpm 9.
- Local dev: `pnpm install && pnpm dev` on port `3545`.
- Production: `pnpm build` → standalone output; the repo `Dockerfile` produces the image Dokploy builds.
- CI: GitHub Actions runs install, lint, and build on every push/PR.

## Failure impact

- The wiki is stateless. Content lives in Git; the Dokploy host holds no unique data. A site outage loses no data — rebuild from `main`.
