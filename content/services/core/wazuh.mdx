Last synced with live infrastructure: **September 2026**.

The firewall sees packets; Wazuh is supposed to see stories. Suricata and CrowdSec on OPNsense react in real time at the edge, but they cannot tell you that a host started behaving strangely three days ago — that is the SIEM's job, once agents report in. Today Wazuh is deployed and reachable but young: the dashboard is up, the agent fleet is not yet inventoried, and alerting is still to be defined. Treat this page as a construction site with a clear direction rather than a finished reference.

## Ingress

`wazuh.cleeryy.cloud` → Caddy → `https://wazuh:443` (`tls_insecure_skip_verify`). No SSO gate currently — hardening tracked in the [migration plan](/architecture/migration-plan).

## Role

Central security monitoring alongside OPNsense Suricata/CrowdSec. Agent deployment across internal hosts is the expected next step; the enrolled-agent inventory is pending.

## Failure impact

- Wazuh down → loss of centralised security visibility; no production traffic impact.
