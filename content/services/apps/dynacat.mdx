Last synced with live infrastructure: **September 2026**.

With dozens of hostnames in the air, nobody remembers them all — Dynacat is the start page that remembers for you. One dashboard with a tile per service turns the whole homelab into something guests and family can actually use without a guided tour. It holds no data and fronts nothing sensitive, so it sits deliberately low in every priority list on this site: nice to have, trivial to rebuild, first thing to check when someone says "what do we run here, actually".

## Placement

- LXC `151` `dynacat` on `pve3` (production VLAN, `10.1.20.51` tag; 2 GB RAM).

## Ingress

`dashboard.cleeryy.cloud` → Caddy → `dynacat:8080`. No SSO gate currently.

## Role

Start-page dashboard linking the homelab services. Stateless; configuration is the asset.

## Failure impact

- Dynacat down → operators lose the start page; all services remain directly reachable.

## Known gaps

Where the dashboard definition lives (and therefore how to restore it) is undocumented, and SSO is a deliberate non-priority for a page of links. One sentence answering the first would finish this page.
