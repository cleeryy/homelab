Last synced with live infrastructure: **September 2026**.

This is the friendly face over whatever language models the homelab talks to: one chat UI in the browser instead of API keys scattered across laptops. The frontend itself is stateless and boring; all the security and cost questions live in the backend provider it points at — which model, whose API key, who gets billed. That is why the pending list on this page is dominated by provider wiring and SSO rather than by the container, which more or less runs itself.

## Placement

- LXC `131` `openwebui` on `pve3` (production VLAN, `10.1.20.31` tag; 8 GB RAM).

## Ingress

`chat.cleeryy.cloud` → Caddy → `openwebui:8080`. No SSO gate currently — SSO is recommended for any AI frontend holding API keys.

## Dependencies

- Backend model provider (local inference vs. hosted API) is not captured here; the backing provider determines the real failure domain.

## Failure impact

- A `pve3` outage takes the frontend down; hosted-model usage from other clients is unaffected.

## Known gaps

The backend provider wiring (local vs. hosted, whose key, who pays) is undocumented, the SSO decision is open despite API keys being involved, and the backup posture for chats and settings is unknown. The first item is the one to resolve; the rest follows from it.
