## Notes

- "Beszel label" and "IP" come from Beszel's host list and apply only to the Docker host VMs. LXC IPs follow the tag convention (`20.x` → `10.1.20.x`, `50.x` → `10.1.50.x`, `1.x` → `192.168.1.x`) and are confirmed only where a service binding, NAT rule, or DNS record pins them.
- This table is observed placement, not target placement. There is no implied recommendation to move any service in this view; see the [migration plan](/architecture/migration-plan) for in-flight transitions.
